Omar Rasheed Social Media Video Downloader ...

موقع صفحة واحدة حديث لتحميل الفيديوهات من مواقع التواصل الاجتماعي (يوتيوب، تيك توك، انستغرام، فيسبوك، تويتر/X، فيميو، وغيرها الكثير) بصيغة **MP4** أو **MP3** مع اختيار الدقة.

## المميزات

- تصميم عصري داكن مريح للعين (Dark Mode + Glassmorphism)
- دعم كامل للغة العربية (RTL)
- تحليل الرابط وعرض العنوان والصورة المصغرة والمنصة
- اختيار جودة الفيديو (4K / 1440p / 1080p / 720p / 480p / 360p ...)
- تحويل مباشر إلى MP3 بجودة عالية
- بدون تسجيل دخول
- يعمل محلياً على جهازك

## المتطلبات

- Python 3.10 أو أحدث
- FFmpeg (مطلوب لاستخراج الصوت MP3 ودمج الفيديو)

### تثبيت FFmpeg

**Ubuntu / Debian:**
```bash
sudo apt update && sudo apt install ffmpeg
```

**macOS (Homebrew):**
```bash
brew install ffmpeg
```

**Windows:**
حمّل من [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html) أو استخدم `winget install ffmpeg`

## التشغيل السريع

```bash
# 1. انتقل إلى المجلد
cd media-safe

# 2. أنشئ بيئة افتراضية (موصى به)
python3 -m venv venv
source venv/bin/activate          # Linux / macOS
# أو على Windows: venv\Scripts\activate

# 3. ثبّت المكتبات
pip install -r requirements.txt

# 4. شغّل الخادم
python app.py
```

ثم افتح المتصفح على:

**http://127.0.0.1:5000**

## كيفية الاستخدام

1. الصق رابط الفيديو في الحقل
2. اضغط **تحليل**
3. اختر **فيديو MP4** أو **صوت MP3**
4. اختر الدقة المطلوبة (للفيديو)
5. اضغط **تحميل الآن** وانتظر حتى يبدأ التحميل

## ملاحظات هامة

- الأداة تستخدم [yt-dlp](https://github.com/yt-dlp/yt-dlp) وهو يدعم أكثر من 1000 موقع.
- الملفات تُحمّل مؤقتاً على جهازك ثم تُحذف تلقائياً بعد الإرسال.
- **احترم حقوق النشر**: استخدم الأداة فقط للمحتوى الذي تملك حقوقه أو المحتوى العام/المرخص.
- بعض الفيديوهات الخاصة أو المحمية قد لا تعمل.
- يوتيوب قد يحدّ من الطلبات الكثيرة من نفس الـ IP.

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| `ffmpeg not found` | ثبّت FFmpeg كما فوق |
| فيديو يوتيوب ناقص الجودات | تأكد أن Node.js مثبت (yt-dlp يستخدمه) |
| خطأ "Unsupported URL" | الرابط غير مدعوم أو غير صحيح |
| التحميل بطيء | الفيديوهات عالية الدقة كبيرة الحجم |
